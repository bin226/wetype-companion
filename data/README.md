# Supplementary dictionary (archived, disabled by default)

Runtime has been rolled back to Qingjian only. CC-CEDICT and personal sources are not loaded unless explicitly requested through Get-LocalLexicon -IncludeSupplementary for development experiments.

`cedict.u8` is an unmodified CC-CEDICT snapshot downloaded from MDBG. Original headers are retained. Traditional and simplified spellings are both indexed; repeated entries are combined into at most two definitions for the compact overlay.

Source and attribution: CC-CEDICT contributors, https://www.mdbg.net/chinese/dictionary?page=cc-cedict and https://cc-cedict.org/ . CC-CEDICT was continued from CEDICT, started by Paul Denisowski.

Data license: Creative Commons Attribution-ShareAlike 4.0 International, https://creativecommons.org/licenses/by-sa/4.0/ . The data retains its own license, separate from the project's GPL source code and Qingjian glossary. Derived CC-CEDICT data must retain attribution and share-alike terms.

`cedict-source.json` records URL, timestamp, entry count and SHA-256. Run `Update-Cedict.ps1` to explicitly download an update; normal startup never accesses the network.

`wordlist.txt` and `wordlist-stats.json` are generated by `Build-Wordlist.ps1` and excluded from Git. The default exported wordlist currently contains only Qingjian words; it is sorted by ordinal order, not frequency. Use it for recognition experiments, not to guess the closest word automatically. Distribution of the combined wordlist must preserve the licenses of its sources.
