# C# 主程序重构验证（2026-10-04）

界面、词库、轮询、设置、自启动、TSV 导入和 CC-CEDICT 在线更新迁到 C#，主程序不再引用 System.Management.Automation，也不启动 PowerShell。Python OCR 的模型、协议、阈值和预处理保留。

CC-CEDICT 临时解析表改为内联的两条释义结构，避免每个词条分配 List 及其数组；传统字和简体字相同时不重复处理。原先词库优先级、重复释义合并和词表行为通过旧词库测试。

两个进程在 20 秒无候选输入的空闲测量中 CPU 增量约为零。未测持续输入的峰值或长时间内存增长。
